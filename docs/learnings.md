## Уроки
1. Цена только из ответа search_catalog; итог заказа называем главным, цену за метр только пояснением.
2. Итог берём с карточки товара на сайте. Считать цену за метр на длину нельзя: сайт округляет.
3. Плитку продают коробками. Бот называет цену за м²; объём считает только по просьбе, из данных поиска (число коробок и итог), с запасом 10%.
4. Нельзя складывать цены разных товаров и подбирать комбинации длин. Можно умножить цену штуки на целое число одинаковых штук.
5. Если в новогодней категории нет нужной длины, повторить поиск без фильтра christmas (садовые гирлянды лежат в других разделах).
6. Если IP на сайте не указан, не выдумывать: сказать, что менеджер уточнит.
7. Запрос на живого менеджера выполняем сразу: имя, телефон, время звонка, без продаж.
8. Поиск по каталогу: русские и английские слова переводятся в латышские корни, лишние слова (цвет) отбрасываются, размер 60x60 сохраняется.
9. Короткий вопрос клиента: один уточняющий вопрос за реплику (тест «Коротко» нашёл, что бот задавал два сразу; правило добавлено в промпт).
